# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be welcoming, respectful and constructive; assume good intent;
no harassment, discrimination, personal attacks or publishing others'
private information. The code of conduct applies in all project spaces
(issues, pull requests, discussions) and when representing the project.

## Reporting

Report unacceptable behaviour privately to the maintainer,
[@echaouchna](https://github.com/echaouchna) on GitHub. Reports are handled
confidentially.
Maintainers may remove content, warn, or temporarily or permanently ban
contributors, following the enforcement guidelines of the Contributor
Covenant.
